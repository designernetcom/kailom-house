## Getting Started

First, run the development server:

```bash
npm run dev
# or
yarn dev
# or
pnpm dev
# or
bun dev
```

Open [http://localhost:3000](http://localhost:3000) with your browser to see the result.

## Run with the Java backend

The product quote form is connected to the Spring Boot API in `../java-backend`.
Start the API in a second terminal first:

```bash
cd ../java-backend
mvn spring-boot:run
```

Then start Next.js from this directory. The frontend proxy uses
`http://localhost:8080` by default. To override it, copy `.env.example` to
`.env.local` and set `JAVA_BACKEND_URL`.

Open [http://localhost:3000/admin/login](http://localhost:3000/admin/login) to manage the catalogue. The initial admin credentials come from `ADMIN_EMAIL` and `ADMIN_PASSWORD` in the Java backend environment. Published CMS content is available at [http://localhost:3000/catalogue](http://localhost:3000/catalogue).

You can start editing the page by modifying `app/page.tsx`. The page auto-updates as you edit the file.

This project uses [`next/font`](https://nextjs.org/docs/app/building-your-application/optimizing/fonts) to automatically optimize and load [Geist](https://vercel.com/font), a new font family for Vercel.
